# Student Task Management System

## Purpose
A small browser-based application that displays student tasks and lets a user add new ones.

## Features
- View a list of tasks.
- Add a new task with a title and description.
- Validation to prevent blank submissions.

## File Structure
- `index.html`: Main structure and layout.
- `style.css`: Visual design and responsive layout.
- `script.js`: Logic for adding tasks and validation.
- `.gitignore`: Files to be ignored by Git.

## Usage
Open `index.html` in any modern web browser (like Chrome or Edge) to use the application.
